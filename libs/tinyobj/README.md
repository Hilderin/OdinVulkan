# Odin's tiny_obj

A tiny but powerful [Wavefront .obj](http://www.fileformat.info/format/material/) loader written in **Odin**.

This is a port of the [tinyobjloader\_c](https://github.com/syoyo/tinyobjloader-c) library (which is itself a C port of the C++ [tinyobjloader](https://github.com/syoyo/tinyobjloader)) from [https://github.com/algo-boyz/tinyobj](https://github.com/algo-boyz/tinyobj).
